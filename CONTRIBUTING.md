# Contributing

This repository is still in an early stage, so the most useful contributions are usually small, clear, and easy to verify.

Issues, suggestions, and focused pull requests are welcome. If you are planning a larger change, open an issue first so the scope and direction can be aligned before implementation work starts.

Please keep contributions:

- narrow in scope
- technically clear and honest about limitations
- consistent with the repository's emphasis on structured iteration, reproducibility, and transparent documentation

If a change affects project framing, interfaces, or expected workflow, update the relevant documentation in the same pull request.

By contributing, you agree that your contributions will be distributed under the repository license.

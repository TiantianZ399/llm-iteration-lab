# Contributing

This repository is still in an early stage. The current priority is to establish a clean public baseline for the benchmark, document assumptions clearly, and make future extensions easier to review.

Issues, suggestions, and small focused pull requests are welcome. If you are planning a larger change, open an issue first so the direction can be discussed before implementation work starts.

Please keep contributions:

- Scoped and easy to review
- Explicit about assumptions and limitations
- Consistent with the repository's emphasis on reproducibility and clear documentation

If a change affects project structure, commands, or expected outputs, update the relevant documentation in the same pull request.

By contributing, you agree that your contributions will be distributed under the repository license.

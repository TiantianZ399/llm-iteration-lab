# Roadmap

This roadmap reflects the repository's current public scope. Dates are intentionally omitted until the implementation plan is more stable.

## Phase 1: Repository setup

- Establish a clean public README, license, contribution guide, and baseline repository structure
- Make the current shortest-path benchmark inspectable without requiring private context
- Keep repository-level documentation separate from generated experiment artifacts

## Phase 2: Documentation refinement

- Improve setup and reproduction instructions
- Document task assumptions, evaluation metrics, and benchmark limitations more clearly
- Clarify which files are source inputs and which files are generated outputs

## Phase 3: Prototype implementation

- Refactor the current benchmark script into clearer reusable components
- Expose a more explicit configuration surface for experiments
- Tighten baseline definitions and naming where needed

## Phase 4: Examples, benchmarks, and reproducibility

- Add additional benchmark variants when they are ready for public release
- Provide example runs and expected outputs
- Add lightweight reproducibility checks around the current artifact pipeline

## Phase 5: Public release milestones

- Prepare a first tagged public release once the repository layout stabilizes
- Add citation metadata when there is a citable draft or paper to reference
- Expand contributor and governance documentation as collaboration broadens
